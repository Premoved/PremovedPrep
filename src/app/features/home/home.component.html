Welcome to PremovedPrep!

PremovedPrep is a free and accessible platform for chess analysis, exploring database games, studying opponents and building repertoires.

An all in one tournament preparation tool for chess players — designed by a professional amateur.

Default tools

  • The site's game database is built from all Lichess Broadcast archives, containing mostly over-the-board games.
  • The site is using Stockfish 18 (WebAssembly), running in your own browser.
  • The site is using the Lichess tablebase API for Syzygy endgame tablebases
  • Player profiles and ratings come from the official FIDE rating list from the beginning of the current month.
  • The chess board is drawn with Chessground, by Lichess.
  • Piece sets and board sounds — Lichess artwork and recordings

Analysis Board

The pawn.

The central component

  • The extendable utility menu includes functions for setting up a custom position, copying the FEN or the PGN, and exporting positions as jpg images.
  • The analysis is organized in a variation tree displayed in the notation section. It supports navigation, drawing arrows, comments and annotations, and folding the notation.
  • The openings book lists all played moves found in the database for the current displayed position. It specifies, for each move, the number of times it has been played, the score for each colour after being played, and the game of the highest rated player who has played that move.
  • The games list lists all games from the database that have reached the current displayed position. It supports sorting by column values, and a selected game can be navigated quickly without adding it to the variation tree.

Library

The bishop.

A place for keeping ideas organized.

  • You can create multiple collections, each containing multiple PGN game-files. The library organizes game-files into three types, which you can use interchangeably however you like:
    • game — an actual game played between two players.
    • analysis — anything, from an opening idea to an unusual endgame.
    • study — a special format that allows you to hide the solution or the continuation at specific positions.

Repertoire

The rook.

A place for keeping opening preparation.

  • You can create multiple collections for each of the two repertoires, each containing multiple PGN game-files. The repertoire organizes game-files into two types:
    • main-line — meant for the moves which you would like to remember going into a game.
    • model-game — selected games or additional analysis played from the main line.
  • The repertoire automatically links each model-game to a main-line file in its collection — based on the deepest position overlap. The main-line files are then all used to build a repertoire tree for each colour, which is then used to generate the advanced reports against opponents.

Database Search

The knight.

A place for scouting opponents and exploring database games.

  • Two types of searches: one for opponent preparation, and one by multiple game details.
  • Results are displayed in a list of games, but can be navigated in a Player's opening tree as well.
  • Advanced report. When searching for an opponent you can consult an advanced report that compares your own private repertoire with the games of your opponent. The result is a quick visual representation tree that highlights 2 key areas:
    • Deviations — moves that your opponent has made which you have not covered inside your own repertoire.
    • Overlaps — the position before the player playing your opponent has made a move which you would not make.

Account & Desktop agent

  • Each registered user is allocated 2 MB of cloud storage — a save or an import that crosses 2 MB is allowed to finish, so you may see something like 2.2 MB / 2 MB.
  • As a solution for additional storage, the Desktop agent acts as a bridge between this site and your computer. It allows you to use your own game archive as the Database, your own chess engine for analysis, and as much storage as your disk has.
